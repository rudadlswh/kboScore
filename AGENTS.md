## iOS app rules
- Apple-first only
- Swift + SwiftUI only
- Prefer Swift Concurrency over Dispatch/Combine
- Prefer Swift Testing
- Prefer #Preview over PreviewProvider
- Read existing files before editing
- Keep changes scoped and minimal
- Do not change project settings unless required for compilation
- Build before finishing
- If something cannot be completed, leave a clear TODO and keep the project compiling

- Compact, scan-friendly sports dashboard feel
- Preserve reusable component structure
